# 21 — Phase-Wise Rollout

## Phase 0: Validation (Week 1-4) — NO CODE
- Join 20+ Telegram/Facebook coupon groups
- Manually broker 50+ trades (YOU are the escrow)
- Document every transaction, fraud attempt, learning
- Legal consultation (₹50K-1L)
- Go/No-go decision

## Phase 1: MVP (Month 1-3) 🚀
**Build:** Phone OTP auth, voucher listing (20 brands), browse+search, UPI payments (Razorpay), escrow, code reveal (encrypted+watermarked), 2hr timer+auto-confirm, basic dispute flow, push notifications, duplicate detection
**Skip:** KYC, trust scores, auto-verification, advanced fraud, admin dashboard
**Launch:** 200-user closed beta from Telegram groups
**Target:** 500 users, 100 transactions

## Phase 2: Trust & Safety (Month 4-6) 📈
**Build:** Aadhaar KYC, bank verification, trust scores+tiers, device fingerprinting, seller strikes, buyer dispute tracking, admin dashboard, email notifications, analytics
**Growth:** Open to public, referral program, seller incentives
**Target:** 5,000 users, 1,000 txns/month

## Phase 3: Intelligence (Month 7-12) 🏰
**Build:** Auto-verification APIs, guaranteed vouchers, 3-layer fraud pipeline, fraud dashboard, Elasticsearch, price engine, swap feature, WhatsApp notifications, bulk listing
**Growth:** Influencer partnerships, corporate HR integrations, content marketing
**Target:** 50,000 users, 5,000 txns/month, ₹5L revenue/month

## Phase 4: Scale (Year 2) 🚀🚀
**Build:** Corporate tie-ups, bank partnerships, subscription box, API for other apps, AI fraud detection, microservices migration
**Target:** 500K users, 50K txns/month
