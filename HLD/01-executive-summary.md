# 01 — Executive Summary

## What
A two-sided marketplace where users SELL unused vouchers/coupons/gift cards and other users BUY them at a discount.

## Why
- 100M+ credit card users in India
- ₹30,000 Cr+ gift card market growing 25% YoY
- 30-40% of rewards go unredeemed
- ₹6,000-15,000 Cr WASTED annually

## Core Principle
> "Neither party should be able to cheat the other. The platform is the trusted middleman."

## How It Works
```
1. Seller lists unused voucher → code encrypted immediately
2. Buyer pays → money goes to ESCROW (not seller)
3. Code revealed to buyer securely
4. Buyer has 2 hours to verify code works
5. Code works → escrow releases money to seller
6. Code doesn't work → dispute flow, evidence-based resolution
7. No response → auto-confirm after timeout
```

## Revenue Model

| Stream | Mechanism | Share |
|--------|-----------|-------|
| Marketplace Commission | 10-15% from seller | 70% |
| Buyer Convenience Fee | ₹5-15 per txn | 10% |
| Featured Listings | Sellers pay for visibility | 5% |
| Guaranteed Vouchers | Buy at 70%, sell at 85% | 10% |
| Corporate Plans | SaaS for employee voucher resale | 5% |

## Unit Economics
```
Avg Voucher Face Value:     ₹500
Avg Selling Price:          ₹400 (20% discount)
Platform Commission (12%):  ₹48
Payment Gateway Fee (2%):   ₹8
Net Revenue/Transaction:    ₹40
```

## Key Risks

| Risk | Severity | Mitigation |
|------|----------|-----------|
| Seller lists invalid code | 🔴 Critical | Escrow + auto-verification + trust scoring |
| Buyer claims false invalid | 🔴 Critical | Proof-based disputes + behavior analysis |
| Brands send C&D | 🔴 High | Legal structure, gift card focus, brand partnerships |
| Cold start | 🟡 Medium | Seed from Telegram groups |
| CRED builds this | 🟡 Medium | Move fast, acquisition target |
